## ⚡ Interactive Storytelling Experience

This site has been built ditching the standard "grid of items" approach. Instead, it serves as an interactive timeline that visually moves _with_ you!

- **🎬 Cinematic Dark Mode:** Heavily contrasted typography optimized for focus.
- **🏎️ Lenis Smooth Scrolling:** Buttery-smooth interpolations eliminating native browser tearing.
- **🛠️ Framer Motion:** Micro-interactions natively syncing parallax logic perfectly to your scroll.
- **🔒 Security Priority:** Enterprise-grade philosophies natively translated to the web.

## 🚀 Getting Started Locally

Want to start adjusting the layout or testing components on your machine?

```bash
# 1️⃣ Clone this repository
git clone https://github.com/Xavierfroster/MyPortfolio.git

# 2️⃣ Access the project space
cd MyPortfolio

# 3️⃣ Install node modules (We are using npm by default!)
npm install

# 4️⃣ Launch the development terminal
npm run dev
```

> **Note:** Head over to [http://localhost:3000](http://localhost:3000) 🌐 in your browser!
